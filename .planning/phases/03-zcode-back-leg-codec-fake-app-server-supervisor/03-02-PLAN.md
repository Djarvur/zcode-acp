## Phase Goal

**As a** later-phase implementer on this repo, **I want to** the wrapper's back leg — a JSONL codec for the app-server dialect, a scriptable fake app-server with golden transcripts in CI, a desktop discovery + process supervisor, and a turn state machine — **so that** every later phase is testable without the real desktop bundle.

<objective>
Codec hardening (BRIDGE-01 expansion): turn the tracer's working round-trip into a
contract-locked codec — the WR-02 structural demux rule, id type-safety, single-writer
ordering, bypass precedence, raised-line/malformed-line behavior, and the D-05 reverse-request
router policy (per-method deadline; known-but-unanswered credential-cipher tracked honestly).

Purpose: everything downstream (turn machine cancel lane, supervisor children, Phase 4+ front
leg) trusts these four transport guarantees; they are locked by tests now, at their cheapest.
Output: contract-lock test files + the conn/call/writer refinements they demand, all green
under `-race` and the strict lint gate.
</objective>
