<objective>
Resolve standard and explicitly configured macOS ZCode Desktop bundles into the
existing Install shape with validated metadata and actionable diagnostics.

Purpose: The bridge must select `ZCode.app` before any Linux probe and must never
route a macOS bundle through AppImage mounting.
Output: A pure-Go bundle resolver, mac-app discovery probe, extended override
mapping, and fixture tests.
</objective>

<interfaces>
- `supervisor.Install` remains the single spawn input; `SpawnArgv` already emits
  `[Binary, Entrypoint, "app-server", "--stdio"]`.
- `Install.RequiresMount()` is `AppImage != "" && Root == ""`; a mac app install
  leaves `AppImage` empty.
- `OverrideInstall(path) (Install, bool)` is the single override mapper shared by
  production and the real-desktop test tier.
- `Probers.Override` is the discovery order step 1 seam; `Probers.AppDirs` is the
  Linux AppImage scan seam. A new `MacApps` seam keeps the macOS scan testable.
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem → discovery | An app path and Info.plist are untrusted input |
| override → spawn | A user-supplied path must not escape the bundle via CFBundleExecutable |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-01 | Tampering | CFBundleExecutable | mitigate | Reject separators and `..`; require the binary inside `Contents/MacOS`. |
| T-12-02 | Tampering | app path | mitigate | Resolve symlinks, require an existing directory and regular files. |
| T-12-03 | Elevation | override mapping | mitigate | Validate the full bundle; never return a spawnable shape for an invalid `.app`. |
| T-12-04 | Information Disclosure | diagnostics | mitigate | Rows name paths and plist keys only; no file contents or credentials. |
</threat_model>
