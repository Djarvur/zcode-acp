| Boundary | Description |
|----------|-------------|
| backend reply settings -> client picker | The settings snapshot is backend-controlled; the client trusts it as the offer — wrapper-side edits would make the client pick models the backend refuses |
| client session/new -> response | The response must reflect only confirmed backend state; a guessed currentValue fabricates a selection that does not exist |
