The slice is production-quality: no extraction, no silent fallback, unchanged spawn line/env pair, unchanged JSONL dialect.

Output: `internal/supervisor/mount.go` (PrepareMount/Mount/Stop), `Install.AppImage`/`Version`/`RequiresMount` and `supervisor.OverrideInstall`, mount-aware `run`, and a FUSE-free binary e2e test driven by a scripted fake AppImage runtime.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| wrapper to AppImage runtime | The wrapper executes the user-selected/discovered AppImage as the mount helper; its stdout and exit status are untrusted. |
| helper stdout to mount root | The mount path printed by the helper becomes the app-server root; it must be validated, never adopted verbatim. |
| wrapper temp filesystem | The private 0700 base and the `.mount_*` child are writable by the wrapper user only. |
| mounted tree to app-server exec | Exactly two files are stat-validated and executed: the mount root's zcode and its resources/glm/zcode.cjs argument. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-01 | Tampering | helper environment | high | mitigate | Build the helper env by allowlist (PATH/HOME/TMPDIR) so APPIMAGE_EXTRACT_AND_RUN and loader variables cannot turn the mount into extraction or code injection. |
| T-10-02 | Spoofing | helper stdout mount line | high | mitigate | Accept only an absolute, existing, non-symlink directory one `.mount_*` component under the resolved private base; validate the two expected files; never adopt a line outside the base. |
| T-10-03 | Elevation | private base and mount dir | high | mitigate | Create a 0700 base with MkdirTemp; reject a base containing NUL/CR/LF; never scan or delete other users' /tmp mounts; RemoveAll only the base after proving the mount is gone. |
| T-10-04 | Denial of service | orphaned helper/daemon and stale mounts | high | mitigate | Staged Stop (TERM, grace, group SIGKILL, reap), keepalive-pipe teardown, poll the mount root's zcode entry, and fail the run when the mount remains. |
| T-10-05 | Tampering | helper stdout/stderr log injection | medium | mitigate | Cap both streams at 64 KiB, render observed output with %q, and log full text only at Debug. |
| T-10-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs in this phase; `mise run tidy-diff` enforces the single existing require line and any go get is a plan defect. |
</threat_model>
