<objective>
Complete the override and version seams for the mount-first backend: `--app-server`/`ZCODE_ACP_APP_SERVER` accepts a directory, an app-server binary, or a packed `.AppImage`, with unchanged flag-over-env precedence; a packed value becomes a mount-first Install and a bad value fails at the mount step instead of silently falling through to discovery (MNT-02, MNT-04, DISC-03; D-04, D-09, D-11, D-12).

Output: `supervisor.OverrideInstall` as the single mapper for cmd and the manual tier; version-first `desktopVersion`; selection diagnostics naming layout/version/resolved path; README-facing help strings; binary tests for env, precedence, exit codes, and the version seam.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI flag/env to install mapper | The user-supplied path shape decides between tree, binary, and packed mount acquisition. |
| install mapper to executor | A misclassified .AppImage would be executed as the app-server binary (the GUI path), never serving stdio. |
| mounted install to PAT mint | The client version sent to api.z.ai is derived from the install; a wrong value is wire-visible. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-15 | Spoofing | .AppImage override treated as the app-server binary | high | mitigate | Detect .AppImage on the literal and resolved target, return a packed Install, and let PrepareMount own acquisition; directory branch stays first. |
| T-10-16 | Tampering | shell/path injection through the override | high | mitigate | exec.CommandContext with argv only; the resolved path is one argv element; never a shell; quote only in logs. |
| T-10-17 | Information disclosure | selection diagnostics | low | accept | Layout, version, root, and AppImage paths are not secret; no env, key, or credential value is logged. |
| T-10-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs; `mise run tidy-diff` remains the gate. |
</threat_model>
