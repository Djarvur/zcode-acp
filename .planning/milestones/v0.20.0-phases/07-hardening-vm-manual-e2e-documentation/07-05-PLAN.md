<objective>
The D-03 /model slash-prompt layer (07-CONTEXT.md): the omp dialect sends model
switches as PROMPT TURNS (`/model <name>`), so the front intercepts session/prompt
text starting with `/model`, resolves the selector against the session's confirmed
configOptions, and applies matches through the same setModel machinery the picker uses.
Refusals ride a NEW detail-carrying error seam because the client's matchers read only
code -32603 with a string at data.details — the wrapper's current wireError always
passes data: nil, so without the seam every refusal renders as a generic failure in Orca.

Purpose: the exact Hb string contracts (`Unknown ACP model: `, `No model selected.` —
both startsWith) are SESS-03's string-exact acceptance bar and the `resolvesSelectorsFrom:
18.1.9` claim the version stamp (07-04) makes true.

Output: the intercept + the detail seam + byte-locked happy/refusal/edge rows, `-race`
green; builds on 07-03's composed-tier discipline.

**User story (phase goal, MVP framing):** As an Orca user typing `/model <name>` in
the chat, I want the switch to apply to my live session — and a typo to come back as
the card's own "Unknown ACP model" styling instead of a generic error — so that model
switching feels native to the card.
</objective>
