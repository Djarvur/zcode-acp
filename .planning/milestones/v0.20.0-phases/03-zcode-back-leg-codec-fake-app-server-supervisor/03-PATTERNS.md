## Shared Patterns

1. **Go style traps (apply to EVERY new file)** — the repo's only Go file is the anchor: `cmd/zcode-acp/main.go` — `_, _ = fmt.Fprintln(...)` discard (:22) and nlreturn blank line before return (:23-24). Strict golangci (lll 120, `linters.default: all`): doc comments on exported symbols, no bare returns after statements.
2. **stdout is protocol** — every log/diagnostic goes to stderr (`slog`); probe writes ALL its chatter to `process.stderr` (:392-452, :657-672). In the fake binary and wrapper, a stray stdout write corrupts the stream (ARCHITECTURE Anti-Pattern 2 :452).
3. **Record-honesty discipline** — probe records no-reply verdicts honestly (:144-156, :617-621) and never asserts unread values (WR-04 header honesty :417-419). Carry into: supervisor diagnostics (name every probe), turn machine (deadline expiry recorded, not swallowed — D-05), golden tests (missing frame = fail, not normalize-away).
4. **Provenance discipline** — wire claims cite `docs/protocol/app-server-dialect.md` (3.18.2 truth); zcode-src 3.17.x is corroborating-only and NEVER cited as 3.18.2 truth (dialect §9 drift baseline: exactly 4 methods are bundle-only). Comment style in probe header (:1-39) — file-level provenance banner — is the house pattern.
5. **Tracked-source gate** — zcode-src analog paths cited above are verified git-tracked in the zcode-src repo (`packages/shared/src/zcode-protocol/index.ts`, `apps/zcode-cli/packages/bootstrap/src/zcode-protocol/transport.ts`). Do NOT cite `packages/shared/dist/` (untracked build mirror). In-repo analogs all verified `git ls-files`-tracked. NO code was extracted from zcode-src (cite-and-point per phase rules).
