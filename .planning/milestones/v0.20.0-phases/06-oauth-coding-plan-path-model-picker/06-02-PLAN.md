<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| wrapper -> api.z.ai over HTTPS | The mint chain sends the login token to the official host and receives the PAT; endpoints and shapes are pinned, responses are backend-controlled |
| mint chain -> cache -> consumers | The PAT crosses into the cache and the runtime-headers source; it must never reach disk, logs, or errors |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-SC | Tampering | npm/pip/cargo installs | high | mitigate | Zero new dependencies (stdlib net/http only; STACK.md locks stdlib for exactly these three pinned calls) |
| T-06-04 | Information Disclosure | PAT/login token persisted to disk | high | mitigate | D-04: in-process cache only; TestPatMemoryOnly proves the call graph contains no file-write call and the cache struct has no String()/log rendering; no constructor accepts a path |
| T-06-05 | Tampering / Information Disclosure | MitM or endpoint substitution on the mint chain | high | mitigate | HTTPS-only official origin default (injectable ONLY for httptest vectors); explicit cloned default transport with the effective proxy logged once at construction (Pitfall 7); response bodies never logged — errors carry codes/lengths only |
| T-06-06 | Elevation of Privilege | stale PAT served after a desktop re-login (scope change) | high | mitigate | accountScope computed per mint and compared against the ask's expectedAccountScope at the source layer (06-07) — a mismatch answers the coded scope-invalidated error and never serves the stale token; this plan ships the scope fields + Invalidate surface the check needs |
| T-06-07 | Denial of Service (account hygiene) | duplicate zcode-api-key created under concurrent first-auth races | low | accept | Check-then-create with single-flight mints makes the race window process-local (A2: single-user wrapper; a duplicate key is cosmetic and self-healing — the list-first search prefers the existing name on the next mint) |
