<objective>
Return ACP concurrent-prompt refusals as JSON-RPC error -32003 with data.reason "session_busy" instead of -32600 invalid-request, so Orca's retryBusyPrompts queue engages for the omp card; update the dialect doc and the contract tests.

Purpose: Orca retries a session/prompt only when the error is code -32003 with data.reason === "session_busy" (retry delay 1 s doubling to a 5 s cap, indefinite). The current -32600 refusal is surfaced to the user instead of retried. This is a wire-compatibility defect, not a queueing feature: the agent still runs one turn at a time and still refuses the second prompt; only the refusal shape changes.

Output: a coded busy refusal in the acpport seam and its wire carriage, all three concurrent-prompt rejection sites routed through it, wire-level tests at the seam, SDK and raw-frame layers, and the agent-side contract documented in docs/protocol/acp-client-dialect.md.
