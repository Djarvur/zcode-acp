<objective>
Prevent reasoning state from a source model from leaking into a target model switch, and normalize Orca's enabled/disabled thought writes to levels supported by the currently bound model.

Purpose: the preserved-session fix correctly keeps a rejected switch retryable, but the retry currently resends the source model's confirmed level. Resolve against exact target metadata instead, and reject unrepresentable Off requests before any backend mutation.

Output: one shared pure resolver, target-aware picker and /model payloads, narrowly scoped Orca alias normalization, and composed plus wire-level regressions. No dependencies, catalog changes, lifecycle-classifier changes, or ACP error-mapping changes.
</objective>
