<objective>
Teach `zcode-acp omp` the client's non-interactive text-task contract: recognize `--print` / `--mode text`, read the `@file` prompt, make ONE one-shot `workspace/generateText` app-server call, print plain text on stdout, and exit 0/1/2. Today these invocations fall into the ACP server, read an immediate stdin EOF, and exit 0 with empty stdout — which is exactly Orca's observed `OMP returned an empty chat name. The one-shot dialect method satisfies every one of those flags with no session, no tools, no agent loop, and no title generation.

Assumption delta: no-change — text mode is a new mode beside ACP, not a change to a core assumption; the ACP contract, discovery, auth machinery and supervisor are reused unchanged.
