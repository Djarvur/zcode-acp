**Windows now discovers its installed ZCode desktop natively — per-user tree, per-machine trees, then uninstall-registry records, each admitted only by the invariant spawn tree — so `--app-server` is an optional override there.**

## Implementation

### Seams and layouts

- `Probers` gains `Windows WindowsSeams` (the only Windows-specific seam group; zero on Linux/Darwin).
- `WindowsSeams{Dirs []WindowsInstallDir; Uninstall func() ([]UninstallEntry, error)}`.
- `UninstallEntry{Key, DisplayName, DisplayVersion, InstallLocation, DisplayIcon}` — `Key` is the full hive path used in diagnostics.
- `WindowsInstallDir{Name, Query, Root, Layout}` — `Root == ""` means the host does not define the source.
- Layout labels: `windows-user`, `windows-machine`, `windows-registry`; binary name `ZCode.exe`.

### Probe rows and order

Stage rows are appended inside the existing `Discover` order (override → platform stage → builtin-runtime → builtin-bundled):

1. `windows-localappdata` — `%LOCALAPPDATA%\Programs\ZCode`
2. `windows-programfiles` — `%ProgramFiles%\ZCode`
3. `windows-programfiles-x86` — `%ProgramFiles(x86)%\ZCode` (only when set and different)
4. `windows-registry` — one summary row (`scanned N uninstall records, M matching ZCode`, plus a partial-error note)
5. `windows-registry-entry` — one row per ZCode-named record, `Query` = full registry key path

The not-consulted arm emits exactly one `windows-install` row; an empty `Dirs` emits a `windows-install` row saying no native directory sources are configured. Every attempted source gets a row whether it hits or misses, and the first validated tree wins. `ErrNoInstall` still wraps one diagnostics line per row through the unchanged shared `emptyResultError`.

### Windows wiring (`//go:build windows`)

- `platformBinaryName() = ZCode.exe`; `probeInstallStage` delegates to `windowsInstallStage(p.Windows, found)`.
- `DefaultProbers` fills `Dirs: defaultWindowsDirs()` and `Uninstall: defaultUninstallEntries` — `cmd/zcode-acp/main.go` needed no change.
- `defaultWindowsDirs()` reads `LOCALAPPDATA`, `ProgramFiles`, `ProgramFiles(x86)` and leaves unset roots empty.
- `defaultUninstallEntries()` opens `Software\Microsoft\Windows\CurrentVersion\Uninstall` under HKCU, HKLM (WOW64_64KEY), HKLM (WOW64_32KEY) read-only, enumerates with `ReadSubKeyNames(-1)`, reads the four values, maps `ErrNotExist`/`ErrUnexpectedType` to empty, and returns every readable record plus one `errors.Join`-wrapped error when any hive/subkey failed.
